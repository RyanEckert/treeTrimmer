# treeTrimmer 1.0.0

## Initial Release

* First public release of treeTrimmer
* Core functionality:
  - `tree_trimmer()` function for calibrating hierarchical clustering thresholds
  - Support for explicit list and prefix-based group detection
  - Customizable buffer parameter for safety margins
  - Verbose diagnostic output
  - Structured return object with all calibration details
  
* Documentation:
  - Complete function documentation with examples
  - "Getting Started" vignette
  - "Advanced Usage and Troubleshooting" vignette
  - README with quick start guide
  
* Testing:
  - GitHub Actions CI/CD pipeline
  - R CMD check on multiple platforms
